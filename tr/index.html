Alttre kimdir?

Ben Ali Turan. Alttre, yazılım ve donanım projelerimde kullandığım geliştirici adı. Bilişim teknolojileri öğrencisiyim; frontend arayüzler, Python tabanlı servisler, otonom yapay zekâ ajanları ve robotik üzerinde çalışıyorum. Nebula Team'in kurucu ortaklarından biriyim.

Full-stack çalışmalarımda kullanıcı arayüzü ile arka uç servislerini birlikte geliştiriyorum. Örneğin Hype-NEWS projesinde React tabanlı ön yüz ve Python API kodlarını açık olarak paylaşıyorum.

Bu sayfa çalışmalarımın Türkçe özeti. Projelerin kaynak kodları için aşağıdaki bağlantılara, etkileşimli portföy ve diğer çalışmalar için ana sayfaya bakabilirsiniz.
